# CURL

## Базовый синтаксис:
```bash
curl [опции] URL
```

## Основные опции:

### Методы и данные:
```bash
-X [МЕТОД] — задать HTTP-метод (GET, POST, PUT, DELETE).
-d "текст" или --data "текст" — отправить тело запроса (для POST/PUT).
-H "Заголовок: Значение" — добавить или изменить HTTP-заголовок.
```

### Работа с ответом:
```bash
-i — показать HTTP-заголовки вместе с телом ответа.
-I — показать только HTTP-заголовки (HEAD-запрос).
-o [файл] — сохранить ответ в файл с указанным именем.
-O — сохранить ответ в файл с оригинальным именем с сервера.
-s — "тихий" режим (скрыть шкалу прогресса).
-v — подробный вывод (показать отправляемые заголовки и детали соединения).
Поведение:
-L — следовать редиректам (перенаправлениям).
-u пользователь:пароль — базовая аутентификация.
-A "[строка]" — задать User-Agent (имитация браузера).
-k — игнорировать ошибки SSL-сертификата.
```

### Примеры:

```bash
curl https://site.com — получить страницу.
curl -I https://site.com — посмотреть заголовки.
curl -d "a=1&b=2" -X POST https://api.com — отправить POST-запрос.
curl -O https://site.com/file.zip — скачать файл.
```
