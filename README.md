## Проведение лабораторной работы

### Прямые запросы к серверу

Для начала необходимо выполнить несколько запросов напрямую к серверу **echo_server**. Для этого будет использоваться консольная утилита [curl](./extra/curl.md). 

Для начала отправим простой **GET** без заголовков.
В этом запросе будет:
Метод: GET
Заголовки: Test_Header: true
Тело запроса: "Test_body"

Для этого выполним команду:
```bash
curl -i -d "Test_body" -H 'Test_Header:true' -X GET http://localhost:8080 
```

После выполнения мы получив в выводе команды стандартный HTTP ответ, где в теле ответа будут данные, которые мы отправили в запросе.

Полученный ответ от сервера необходимо разобрать и в писать в разделе [Полученные результаты - Запросы](#зпросы).

Также необходимо отправить запросы:
| Метод | Адрес запрашиваемого ресурса | Заголовки                        | Тело                                 |
| `POST`  | `/new/`                    | `Content-Type: application/json` | `{"ключ1":"значение1", "ключ2":123}` |
| `HEAD`  | `/item/1`                  | `Authorization: token`            | **без тела**                         |

После выполнения нужно также записать результаты в разделе [Полученные результаты - Запросы](#зпросы).

Также выполним через браузер запрос. Для этого откроем браузер, далее откроем **DevTools** (клавиша **F12**),  в открывшейся **DevTools** переёдем на вкладку **Network/Сеть**, после чего введём в адресное поле браузера `http://localhost:8080/broswer/` и перейдём по адресу. После чего во вкладке **Network/Сеть** появится наш запрос. Выбрав его можно посмотреть заголовки запроса, ответа, а также тело ответа. Эти данные также необходжимо разобрать и вписать в [Полученные результаты - Запросы](#зпросы).

### Напстройка NGINX как прокси сервера

Для того, чтобы NGINX проксировал запросы к себе по порту 80 необходимо задать соответствующую конфигурацию.

Для этого в файле (nginx/conf.d/default.conf)[nginx/conf.d/default.conf] уберём оичстим контекст **location** и добавим в **location /**:
- proxy_pass http://echo_server:8080/; (пероксируем **запросы** на **echo_server** по порту **8080** по пути **/**, а ответы обратно)
- proxy_set_header Header-In-Request nginx; (добавляем к **запросу** заголовок **Header-In-Request** со значением **nginx** )
- add_header  Header-In-Response response; (добавляем к **ответу** заголовок **Header-In-Response** со значением **response** )
После того, как будет задана конфигурация необходимо сохранить файл и перезагрузить контейнер командой:
```bash
docker compose restart nginx
```

Если конфигурация задана верно, то аналогичный запрос, который отправлялся ранее но по порту **80** (сервис **nginx** слушает порт 80 в отличае от **echo_server**) выполнится успешно:

```bash
curl -i -d "Test_body" -H 'Test_Header:true' -X GET http://localhost:80
```

После выполнения необходимо аналогично записать в разделе [Полученные результаты - Запросы](#зпросы), также добавив что изменилось в запросе и ответе.

### Напстройка NGINX как балансировщика нагрузки

Далее в файле (nginx/conf.d/default.conf)[nginx/conf.d/default.conf] добавим еще один **location** с **URI** `app1`.

В рамках этой локации необходимо настроить проксирование на узел **hello_world-0** без добавления каких либо заголовков.

После чего перезапустим **nginx** командой:

```bash
docker compose restart nginx
```

И выполним проверку командой: 

```bash
curl http://localhost:80/app1
```

В ответе должно быть имя сервера, на которое мы проксируем запросы.

Далее добавим еще одну секцию **server**, где:

- слушать порт - `80`
- server_name - `127.0.0.1`

Далее в созданный сервер добавим локацию:

- URI - `/`
- Проксировать на **hello_world-1**

После чего перезапустим **nginx** командой:

```bash
docker compose restart nginx
```

После чего отправим одинаковые запросы на **127.0.0.1** и **localhost**, и укажем в [Полученные результаты - Запросы](#зпросы) какой запрос на какой сервер отправляется.

Также необходимо ответить на вопросы в разделе [Полученные результаты](#полученные-результаты) и уничтожить стенд выполнив команду:
```bash
docker compose down
```

После чего создать ветку с вашими инициалами и закоммитить изменения.
